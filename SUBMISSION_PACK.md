# GatewayGS Hackathon 2 - GateMap submission pack

## Project

**GateMap** turns a competition brief and current project evidence into an inspectable AI gate map.

## Built with

Python standard-library HTTP server, Ollama `qwen2.5:1.5b`, HTML5, CSS3, vanilla JavaScript, browser Blob export, and strict JSON response validation.

## AI-use disclosure

The runtime AI is a local Ollama model. GateMap uses it for structured evidence extraction and next-step drafting, then validates the returned schema before rendering. AI coding assistance was also used for implementation drafting and debugging. No brief or project evidence is sent to a hosted service.

## Honest boundary

No public repository, live demo, registration, upload, or Devpost submission is claimed by this local pack.
